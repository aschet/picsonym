# picsonym

picsonym invents a short, evocative, artistic title for an image — from the
text prompt that generated it, or by looking at the image itself — and can
rename image files to their generated titles. Titles are generated by a
pluggable backend: by default, an OpenAI-compatible chat completions API
(a local [Ollama](https://ollama.com) server, or any other compatible
endpoint, including OpenAI's own cloud); implement your own backend to run
a model already loaded in-process instead, with no HTTP call involved (see
[Custom Backends](#custom-backends)).

## Installation

Install from a local checkout into a virtual environment.

**Linux / macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install .
```

**Windows (PowerShell)**

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install .
```

Using the default local backend also requires [Ollama](https://ollama.com)
running with a model pulled, e.g.:

```bash
ollama pull gemma4:e4b
```

`title --prompt`/text-only use works with any chat model; `title --image`
and `rename` need a vision-capable one (`gemma4:e4b` above is one such model).

## Usage

```python
from picsonym import Picsonym

generator = Picsonym(model="gemma4:e4b")

generator.title_from_prompt("a lone lighthouse at dusk")
generator.title_from_image("photo.jpg")

# If photo.jpg carries its own embedded ComfyUI generation prompt, that's
# used together with the image automatically. Pass one explicitly for any
# other image (e.g. one whose prompt you keep elsewhere):
generator.title_from_image("photo.jpg", prompt="a lone lighthouse at dusk")

# Point at a different local model, or a real OpenAI-compatible cloud API
# (set OPENAI_API_KEY for the latter):
generator = Picsonym(model="gpt-5.1-mini", base_url="https://api.openai.com/v1")
```

Renaming:

```python
generator = Picsonym(model="gemma4:e4b")

generator.rename_file("photo.jpg")
# -> RenameResult(original=..., renamed=PosixPath('A Quiet Departure.jpg'), ...)

for result in generator.rename_folder("photos/", recursive=True):
    print(result)
```

Every call re-titles the file, even if its name already looks like a
title — there's no "already titled" detection, so repeated runs over the
same folder will keep regenerating titles.

## Custom Backends

Implement `LLMBackend` to run a model already loaded in-process — e.g.
inside a ComfyUI custom node — instead of the default `OpenAIBackend`:

```python
from picsonym import LLMBackend, Picsonym

class MyLocalBackend:
    def __init__(self, loaded_model):
        self.model = loaded_model

    def generate(self, *, system_prompt: str, user_text: str, image: bytes | None) -> str:
        if image is not None:
            return self.model.caption(image, instruction=f"{system_prompt}\n{user_text}")
        return self.model.complete(f"{system_prompt}\n{user_text}")

generator = Picsonym(backend=MyLocalBackend(loaded_model))
```

picsonym owns the system prompts; the backend owns the call to its model.
Responses go through the same cleaning and validation either way.

## Command Line

Installing the package provides a `picsonym` command. `--model` is always
required; `--base-url` defaults to a local Ollama server.

```bash
picsonym title --model gemma4:e4b --prompt "a lone lighthouse at dusk"
```

```
Waiting For The Dark
```

```bash
picsonym title --model gemma4:e4b --image photo.jpg
picsonym rename --model gemma4:e4b photo.jpg
picsonym rename --model gemma4:e4b --recursive photos/
```

`rename` accepts one or more files or folders. By default a folder is
scanned non-recursively (`--recursive`/`-r` descends into subfolders).
Every file is always re-titled — see [Usage](#usage) above. Run
`picsonym --help` for the full list of options. The module is also
executable via `python -m picsonym`.
